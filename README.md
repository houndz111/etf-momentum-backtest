# ETF Momentum Rotation Backtest

## 项目简介

本项目使用 Python 对五只 ETF 构建横截面动量轮动策略，
研究过去表现较强的 ETF 在随后一个月是否继续具有相对优势。

## 策略规则

1. 使用每月最后一个交易日的前复权收盘价。
2. 计算各 ETF 过去 12 个月的累计收益率。
3. 每月选择动量最高的 1 只 ETF。
4. 信号滞后一个月执行，避免前视偏差。
5. 每月调仓一次。
6. 使用五只 ETF 等权组合作为基准。
7. 加入单边 0.1% 的简化交易成本。
8. 进行时间切分的样本内外表现对比。
9. 对 3、6、9、12、18 个月动量窗口进行探索性敏感性分析。

## 样本内外分析说明

本项目将回测区间按时间划分为样本内和样本外两个阶段：

- 样本内区间：2016-02 至 2021-12
- 样本外区间：2022-01 至 2025-12

样本外区间用于观察策略在不同市场阶段的历史表现。

需要说明的是，本项目的样本内外划分主要用于表现对比，而不是严格意义上的事前样本外验证。研究过程中曾对完整样本进行策略表现和参数敏感性分析，因此样本外结果可能受到研究过程中的数据观察和规则调整影响。

此外，策略信号本身使用月末动量数据，并滞后一个月执行，以避免在单个月度收益计算中使用未来信息。

## 运行方式

### 1. 创建环境

```powershell
conda create -n quant python=3.11
conda activate quant
python -m pip install -r requirements.txt
```

如果本地已经存在 quant 环境，只需执行：
```
conda activate quant
python -m pip install -r requirements.txt
```

### 2. 运行 Notebook
使用 VS Code 打开项目根目录，打开 analysis.ipynb， 并在右上角选择 quant 内核。

按照 Notebook 中的顺序运行代码单元格。

首次运行时，程序会从 AkShare 获取 ETF 数据并保存到：
```
data/raw/
```

后续运行优先读取本地缓存，避免重复请求接口。

### 3. 输出文件
分析结果和图表保存在：
```
outputs/
```

包括绩效表、净值曲线、回撤图和持仓变化图。


## 输出文件

- `outputs/performance.csv`：策略和等权基准的绩效指标
- `outputs/monthly_returns_and_turnover.csv`：月度收益、换手率和交易成本
- `outputs/wealth_comparison.csv`：策略毛净值、净净值和等权基准净值
- `outputs/held_weights.csv`：每月实际持仓权重
- `outputs/sensitivity_results.csv`：不同动量窗口的敏感性分析
- `outputs/drawdown.csv`：策略和基准回撤序列
- `outputs/wealth_comparison.png`：策略净值曲线
- `outputs/drawdown_comparison.png`：策略回撤曲线
- `outputs/monthly_holdings.png`：月度持仓变化图
- `outputs/lookback_sensitivity.png`：动量窗口敏感性图
  
## 主要研究发现

在 2016-02 至 2025-12 的回测区间内，12 个月动量轮动策略的毛累计收益率为 165.96%，扣除单边 0.1% 的简化交易成本后，净累计收益率为 148.90%。

等权基准的累计收益率为 183.80%，高于动量策略净收益。动量策略的年化波动率为 18.63%，约为等权基准的两倍；最大回撤为 -30.14%，也明显高于基准的 -16.49%。策略净收益夏普比率为 0.58，低于基准的 1.20。

样本内外对比显示，动量策略在样本外阶段的表现有所改善。样本外累计收益率为 89.49%，高于同期等权基准的 52.26%；但策略夏普比率为 1.05，仍略低于基准的 1.17，最大回撤为 -11.70%，略高于基准的 -10.61%。

参数敏感性分析显示，策略表现对动量窗口较为敏感。不同窗口的全样本结果存在较大差异，因此不能仅根据全样本最优结果选择参数，也不能将探索性参数比较视为严格的样本外验证。
